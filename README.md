# Обзор проекта

Платформа для подбора курсов по искусственному интеллекту от ведущих вузов Воронежа (ВГУ, ВГТУ, ВГУИТ). Система предоставляет функционал для трёх типов пользователей: работников, работодателей и учебных заведений.
Проект представляет собой готовое к использованию решение для профориентации и подбора курсов. Основной функционал реализован и покрыт тестами. Система легко расширяется для добавления новых опросов и парсеров.

## Технический стек

* **Backend:** Django 6.0, Django REST Framework
* **База данных:** PostgreSQL (с PostGIS)
* **Очереди задач:** Celery + Redis
* **Контейнеризация:** Docker, Docker Compose
* **Фронтенд:** Bootstrap 5, HTMX, Alpine.js, Chart.js
* **Тестирование:** pytest, pytest-django
* **API документация:** DRF

## Основные модули

### 1. Система опросов (Surveys)

Полнофункциональная система опросов с поддержкой множества типов:

1. Цифровая грамотность педагогов
2. Профессиональные склонности Холланда
3. Большая пятёрка (личностные черты)
4. Множественный интеллект

Ключевой функционал:

* Многопопытное прохождение (история результатов)
* Сохранение прогресса (возможность продолжить позже)
* Персонализированные рекомендации (для работников, работодателей, ВУЗов)
* Визуализация результатов (столбчатые диаграммы)
* Импорт опросов из Excel
* Управление интерпретациями через админ-панель

### 2. Организации (Organizations)

Управление организациями (ВУЗами и компаниями) с интеграцией DaData:

* Автоматическое заполнение данных по ИНН из ФНС
* Геокодирование адресов
* Категоризация по районам и типам
* REST API для организаций

API эндпоинты:

```
GET  /api/districts/                      # Список районов
GET  /api/organization-types/             # Типы организаций
GET  /api/organizations/                  # Список организаций
GET  /api/organizations/<id>/             # Детальная информация
GET  /api/organizations/by_district/      # Фильтр по району
GET  /api/organizations/with_coordinates/ # Организации с координатами
```

### 3. Аккаунты и пользователи (Accounts/Users)

Роли пользователей:

* employee — Работник (проходит опросы, заполняет анкету)
* employer — Работодатель (управляет профилем организации)
* university — ВУЗ (аналогично работодателю, но с доп. полями)
* admin — Администратор

Регистрация:
* Работодатели: через форму заявки -> одобрение администратором
* Работники: саморегистрация с привязкой к организации

Профили:
* Анкета работника (образование, опыт, должность)
* Профиль организации/ВУЗа (контакты, реквизиты)

### 4. Курсы (Courses)

Модуль для управления курсами с поддержкой:

#### Для университетов:
- Просмотр списка своих курсов (только активные)
- Добавление нового курса (с выбором категорий)
- Редактирование курса
- Мягкое удаление курса (перемещение в корзину)
- Просмотр корзины удалённых курсов
- Восстановление курсов из корзины

### 5. Целеполагание (Goal Setting)
Модуль для сбора целей и ожиданий пользователя от обучения. Является обязательным шагом перед получением рекомендаций.

Функционал:
- Динамические формы с вопросами разных типов:
- - Выбор из вариантов (choice)
- - Множественный выбор (multiple_choice)
- - Текстовый ответ (text)
- - Диапазон дат (date_range)

- Поддержка пользовательских вариантов ответа ("Свой ответ")
- Сохранение прогресса заполнения
- Проверка полноты заполнения через has_completed_goal_setting()

### 6. Система рекомендаций (Recommendations)
Модуль для генерации персонализированных рекомендаций курсов на основе:
- Профиля пользователя (образование, опыт, должность)
- Целеполагания (цели, ожидания, желаемые результаты)
- Результатов опросов (если пройдены)

Архитектура:
- DeepSeekRecommendationService — сервис для работы с DeepSeek API
- - Сбор полного профиля пользователя
- - Подготовка промпта с учётом всех данных
- - Парсинг и валидация ответа AI

- Celery задачи — асинхронная генерация рекомендаций
- - generate_recommendations_for_user — генерация для конкретного пользователя
- - generate_recommendations_for_all_employees — массовая генерация

Условия для генерации:
- Обязательные:
- - Заполненная анкета работника (is_profile_complete())
- - Заполненное целеполагание (has_completed_goal_setting())
- Опциональные:
- - Пройденные опросы (улучшают качество рекомендаций)

Алгоритм работы:
1. Пользователь заполняет анкету и целеполагание
2. Система проверяет готовность через is_ready_for_recommendations()
3. Запускается Celery задача generate_recommendations_for_user
4. Сервис собирает профиль, целеполагание и результаты опросов
5. Формируется промпт для DeepSeek API
6. AI анализирует данные и подбирает курсы с оценкой 50%+
7. Результаты сохраняются в БД
8. Пользователь видит рекомендации с пагинацией по 20 шт.

### 7. Технические задания (Technical Requirements)

Модуль для создания и управления техническими заданиями на разработку образовательных программ.

#### Для работодателя:
- Создание технического задания с динамической формой (вопросы настраиваются через админку)
- Выбор не менее 5 ВУЗов для отправки предложения
- Автоматическая отправка задания выбранным ВУЗам со статусом "Отправлено"
- Просмотр списка своих ТЗ с количеством ВУЗов
- Просмотр статусов по каждому ВУЗу в отдельном окне
- Удаление ТЗ (только для отправленных)

#### Для ВУЗа:
- Просмотр входящих технических заданий от работодателей
- Фильтрация по статусу и поиск по организации
- Изменение статуса ТЗ через выпадающий список
- Детальный просмотр каждого задания со всеми ответами
- Видимость только своего статуса (не видны другие ВУЗы)

#### Для администратора:
- Полный доступ к управлению ТЗ через админ-панель
- Создание ТЗ через ту же форму, что и у работодателя
- Просмотр всех ТЗ и статусов
- Отдельный квадрат на главной странице для быстрого доступа

#### Особенности формы:
- Поддержка 7 типов вопросов (text, textarea, choice, multiple_choice, boolean, date, number)
- Условное отображение полей (зависимость от ответов на предыдущие вопросы)
- Поддержка варианта "Свой вариант" с дополнительным полем ввода
- Адаптивный интерфейс с использованием Bootstrap
- Переключатели с подписями "Да/Нет" для boolean полей
- Динамическое обновление полей без перезагрузки страницы (JavaScript)

#### Статусы:
- **Отправлено** — задание отправлено ВУЗам (устанавливается автоматически)
- **В разработке** — ВУЗ начал работу над заданием
- **Завершено** — задание выполнено
- **Отклонено** — задание отклонено

Статусы настраиваются через админ-панель (можно добавлять/редактировать/удалять, менять цвета).

#### Права доступа:
- **Работодатель** — создание, просмотр, удаление своих ТЗ
- **ВУЗ** — просмотр входящих ТЗ, изменение статуса
- **Администратор** — полный доступ
- **Просмотрщик** — только просмотр (без возможности редактирования)


### 8. Выбранные курсы (Selected Courses)

Функционал для сохранения и управления выбранными курсами:

#### Для работника:
- Выбор курса из списка рекомендаций (кнопка "Выбрать этот курс")
- Просмотр списка выбранных курсов на главной странице
- Удаление курса из выбранных
- Количество выбранных курсов отображается на главной странице

#### Для работодателя:
- Просмотр выбранных курсов каждого сотрудника
- Отображение количества рекомендаций и выбранных курсов в списке сотрудников
- Переход по ссылке на список выбранных курсов сотрудника


## Админ-панель

Кастомизированная через Jazzmin.

Основные разделы:

* Пользователи (управление, импорт/экспорт)
* Организации (управление, DaData-обновление)
* Опросы (категории, блоки, вопросы, интерпретации)
* Курсы (просмотр, управление)
* Технические задания (просмотр, управление статусами)
* Вопросы для формы ТЗ (настройка через админку)

Дополнительные кнопки:

* Парсинг ВГУ / ВГУИТ / ВГТУ / ВГЛТУ / ВГПУ / ВЭПИ / ВГАС / ВИВТ / ВСЕХ
* Импорт опроса из Excel

### Роли и права доступа

#### Группа "Просмотрщик":
Пользователи с этой группой имеют ограниченный доступ:

**Доступно:**
- Просмотр всех моделей в админке
- Экспорт данных (кроме пользователей)

**Запрещено:**
- Добавление, редактирование и удаление любых записей
- Импорт данных (опросы, пользователи)
- Запуск парсинга курсов
- Изменение статусов заявок
- Управление пользователями
